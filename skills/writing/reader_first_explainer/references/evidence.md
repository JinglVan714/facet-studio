# Evidence reference：对视频忠实，不核实世界

> 文章写视频里有的东西；视频没说的，不写。
> 视频事实只来自 evidence；模型知识只做解释/类比/背景。
> 这不是论文，也不是百科全书；不要把每句写成“未核实”的体检报告。

## 1. Evidence 是什么

- `evidence_text`：按观看顺序编译的 edited transcript；frame marker 是 VLM/OCR 的屏幕文字，不是画面语义。
- 用它来取视频事实、数字、名字、引语、演示和说话人。
- 模型知识可以解释概念、给类比、组织背景；不能变成视频里的事实/数字/引语/说话人。

## 2. 一条简单规则

- 视频有 → 写。
- 视频没有 → 不写。
- 视频说“假设/如果/可能/一次测试” → 保留这个 scope；不要写成实测/普遍定律。
- 视频说“X” → 把 X 写成视频里的内容；不要升级成“官方/已证实”，除非视频/来源明确这么说。
- 不编数字、名字、引语、说话人、画面、URL、因果。

## 3. 自然归属

- 写内容，不要每段都“视频里说”。
- 只有在做实事时才用“视频里/作者说/对话里”：区分观点/事实、指向具体演示、或说话人不确定。
- 不要猜说话人。证据没有 speaker label 时，写“视频里/对话里”；源文本用第三人称称呼（“X，你……”）时，那是另一个人在说。不要把最近的人名当成说话人。
- 不要在每条产品/模型 claim 后面加“未核实/待核”。如果一句话可能被读成“官方已证实”，把主语写成“视频里/作者说”一次；source line 记出处。
- 不要为了保守把所有“他/她”都改成“对话里”。上下文明确是谁说的（“咱都是打小过来的”“我说那句话没错”），就保留名字；否则文章会被写平。

## 4. 引语和数字

- 引号只包精确原文；近似的 ASR 变体不是精确引文，去引号改写。
- 数字照抄；不四舍五入、不换算单位、不加精度。指标/任务/baseline 不知道时，不要暗示这是实测；写视频展示了什么。
- 单次演示不是 benchmark；假设不是结果；视频 claim 不是官方事实。
- 如果数字跨句/跨段，确认它在 edited text 里连续；不要自己拼接两个不同语境的数字。

## 5. 边界

- 边界是读者向的：证据能让读者得出什么/不能得出什么。
- 不要列“证据缺什么”的审计清单；写影响读者判断的限制。
- 正文和边界用同一个 scope。

## 6. Source line

- 结尾一行，短、自然：视频 id、频道、标题/日期（有就写；没有就简单说“未提供”）。
- 不编 URL/日期/官方文档；frame OCR/水印只是 hint，不是官方事实。
- 来源行是出处，不是核实报告；一两句就够。不要把“未核实”铺满正文，也不要把 source line 写成法律免责声明。

## 7. 自检

1. 每个视频事实/数字/引语/名字/说话人都在 evidence 里吗？
2. 有没有把假设/单次演示/单次测试写成实测/普遍定律？
3. 有没有把视频 claim 写成“官方/已证实”？
4. 引号是否精确？转述是否去引号？
5. 归属是否自然，不是每段“视频里”？
6. source line 是否短、诚实、没有编 URL？
