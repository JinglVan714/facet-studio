# 3 分钟 demo 脚本

> 目标：让陌生人在 3 分钟内看懂“视频 → 一种形态 → 聊天预览 → 人工验收 → 可排查”。
> 只录产品链路，不录架构页/评测页；不用 B 站视频帧做素材。

## 录制前

- 起服务：Mongo → preview → LibreChat（见 [integrations/librechat/README.md](../integrations/librechat/README.md)）。
- 准备一条**自己有权限**的短视频（或直接用 `examples/demo/` 的样本讲产物）。
- 清理聊天侧栏，只留一个会话；关掉无关窗口。
- 分辨率 1440×900 或 1920×1080；不要出现邮箱/API key/本地绝对路径。

## 分镜

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0:00–0:20 | README 首屏 + 一句定位 | “给一条视频和写作要求，Agent 按需写成一种形态，聊天里预览、验收。” |
| 0:20–1:10 | 聊天输入 BV + “写一篇小红书，给刷信息流的人看” | 后台 run；运行卡出现“读取 → 规划 → 写作 → 排版”；视觉审计显示“4 候选 / 0 通过，本次不用视频截图” |
| 1:10–1:50 | 右侧预览抽屉：小红书卡片 + 正文 | “成品是排版后的，不是裸 Markdown；Markdown 仍可编辑/复制。” |
| 1:50–2:20 | 回一句“开头再短一点” → 新版本 | “修改 = 新 writer 请求，不是 editor 改稿；旧版本保留。” |
| 2:20–2:45 | `/runs/<run_id>`：Trace / Stats | “stage / LLM call / tool span / decision / token / latency 都能下钻；checks 是机器检查，不是写作质量分。” |
| 2:45–3:00 | 点“验收通过” → 状态 approved | “人工验收是唯一发布门；不自动发布。” |

## 不要录

- 架构页、评测页、内部 handoff、简历/Job 文档。
- 第三方视频帧/封面；需要画面时用 `examples/demo/` 的文字封面卡或自制流程图。
- 任何 token/成本数字被说成“用户 SLA”；说明这是本地机器链路，不含人工验收等待。
